# Mini CBT Flask App

This is a simple Computer-Based Test (CBT) system built using Flask.

## Features
- User enters name and matric number
- Answer multiple-choice questions
- Score is calculated automatically
- Result is displayed with user details

## How to Run

1. Install Python
2. Install Flask:
   python -m pip install flask

3. Run the app:
   python app.py

4. Open browser:
   http://127.0.0.1:5000
